# Atlas — Constitutional Execution: USR, UCA, UCD

*From constitution to action.*

---

## USR / CoreFab — Universal Constitutional Execution Engine

### Origin
The Constitution and its sciences define what is true and what is governed. But truth without action is inert. USR is where constitutional logic becomes **constitutional action** — the runtime that executes constitutional operations with sovereignty guarantees.

### Nature
USR is the **constitutional runtime**. It does not execute arbitrary code; it executes *constitutional operations* — operations that are verified, traceable, and sovereign. In ICore, every execution must be constitutionally grounded.

### Structure
```
USR/CoreFab provides:
├── Execution — running constitutional operations
├── Provenance — tracking where every operation came from
├── Sovereignty — ensuring external systems cannot override internal logic
└── Minimalism — running on constrained hardware (Android, Fossil, etc.)
```

### Culture
USR is the constitution's **muscle**. It takes the Constitution's abstract authority and makes it concrete — executing operations, processing data, producing outputs. But it does so under constitutional governance: every operation is verified, every result is traceable.

**Key constraint:** USR never executes anything that has not been verified by the constitutional stack above it. Trust is not assumed; it is proven before execution.

---

## UCA — Universal Constitutional Adapter

### Origin
The constitution must interface with the outside world — DNS for naming, WASM for execution, Rust for performance, Deno for scripting, Syncthing for storage. UCA is the **boundary layer** between the constitution and external systems.

### Nature
UCA is the **constitutional boundary**. It is the last constitutional layer — everything beyond UCA is external, never part of the constitution itself. This is a critical sovereignty boundary: the constitution depends on nothing external, but external systems can depend on the constitution.

### Structure
```
UCA adapts to:
├── Naming — DNS, ENS, Handshake, custom namespaces
├── Storage — local files, Syncthing, IPFS (read-only)
├── Execution — WASM, Rust, Deno, Node.js
├── Communication — HTTP, WebSocket, message queues
└── Future Infrastructure — any new external system
```

### Culture
UCA is the constitution's **handshake with the world**. It is how ICore talks to the internet, to devices, to other systems — without ever surrendering sovereignty. The adapter is controlled by the constitution, never the reverse.

**Key rule (D4):** Adaptation is the boundary. Everything beyond UCA is external. The constitution never depends on an adapter.

---

## UCD — Universal Constitutional Derivatives

### Origin
After the constitution, its sciences, its models, and its runtime, there are **building blocks** — pre-built, verified components that implementations can compose without re-deriving from first principles. UCD provides these derivatives.

### Nature
UCD is the **constitutional toolkit**. It contains ready-made components that have been derived from the constitutional stack and verified as constitutionally compliant. Implementations compose these components rather than building from scratch.

### Structure
```
UCD provides:
├── Identity Components — pre-built identity verification
├── Verification Components — pre-built verification checks
├── Governance Components — pre-built governance pipelines
├── Data Components — pre-built data models and transforms
└── Integration Components — pre-built adapter configurations
```

### Culture
UCD is the constitution's **practical toolkit**. It translates high constitutional theory into ready-to-use building blocks. An implementer does not need to understand the full derivation from Reality to USCP to build something — they can start with UCD components and compose upward.

**Key rule (D5):** Derivatives are composed, not derived. UCD elements are assembled from UCA capabilities; they do not re-derive the kernel.

---

*USR, UCA, and UCD form the constitutional execution stack: runtime (do it), adapter (connect to the world), derivatives (ready-made building blocks).*
