# Atlas — Implementation Layer: CodeLabs & Studio

*Where constitution meets the world.*

---

## CodeLabs

### Origin
The Constitution and its full stack provide governance, verification, and execution. But new ideas need a **proving ground** — a sandboxed space where untested concepts can be explored without risking the constitutional foundation. CodeLabs is that space.

### Nature
CodeLabs is the **constitutional experimentation environment**. It is where ICore.Gate fulfills its primary function: prototyping, validating, and refining new ideas before they enter the stable kernel. CodeLabs is not separate from the constitution; it is the constitution's **research laboratory**.

### Structure
```
CodeLabs provides:
├── Sandboxing — experiments cannot corrupt the kernel
├── Verification — experiments are checked against constitutional tests
├── Promotion — validated experiments enter the stable kernel
└── Archival — rejected experiments are preserved for reference
```

### Culture
CodeLabs is the constitution's **immune system for innovation**. It allows exploration without risk. New ideas are tested, verified, and only promoted if they pass constitutional verification. This is how ICore grows without breaking.

**Key principle:** CodeLabs runs on the full constitutional stack (via UCA). Experimentation requires the complete foundation to be meaningful — isolated experiments cannot be constitutionally evaluated.

---

## Studio (studio.initialcore.net)

### Origin
CodeLabs, the Constitutional Atlas, governance tools, verification systems, and all constitutional components need a **unified interface** — a single entry point where all constitutional work happens. Studio is that interface.

### Nature
Studio is the **constitutional workspace**. It integrates everything — CodeLabs for experimentation, the Atlas for navigation, governance tools for evolution, verification tools for trust — into one sovereign, accessible interface. Studio is the outermost layer; external users interact with ICore through Studio.

### Structure
```
Studio integrates:
├── Constitutional Atlas — navigate and understand the constitution
├── CodeLabs — experiment and prototype
├── Governance — propose, review, verify, ratify changes
├── Verification — check integrity and provenance
├── Visualization — interactive constitutional understanding
└── Runtime — execute constitutional operations
```

### Culture
Studio is the constitution's **public face**. It is where humans meet the constitution — where they can read it, understand it, govern it, and use it. Studio must be accessible (Android-first, offline-capable) while remaining sovereign (zero cloud lock-in).

**Key principle:** Studio depends on everything beneath it but nothing depends on Studio. It is the outermost layer — the interface, not the foundation.
