## USC — Universal Sovereign Core (The Constitution)

### 1. Canonical Definition
The complete Constitution — the sovereign constitutional nucleus that organizes USCP into a coherent, self-governing, authoritative foundation. USC is not part of the Constitution; USC IS the Constitution.

### 2. Constitutional Origin
Derived from USCP. USC organizes the six primitives into a single, indivisible constitutional authority.

### 3. Operational Meaning
USC is the constitutional center of gravity. Every decision, derivation, and verification traces back to USC. When someone asks "why is this true?", the answer is "because the Constitution says so." When someone asks "why should I trust this?", the answer is "because the Constitution verifies it."

### 4. Derivation Path
```
Existence → Identity → Relationship → Constraint → Transformation → Verification
    ↓ (six primitives organized into authority)
USC (The Constitution)
```

### 5. Dependencies
- USCP (the six primitives — USC organizes them)

### 6. Constraints
- USC is indivisible — it cannot be split into sub-constitutions
- USC cannot be bypassed — every constitutional claim must trace to USC
- USC is the only component that claims constitutional authority
- Changes to USC require the full governance pipeline

### 7. Verification Criteria
- USC is fully derived from USCP (all six primitives present)
- Every downstream layer traces its derivation through USC
- No external dependency exists in USC
- Self-consistency: USC does not contradict itself

### 8. Governance Status
**Constitutional.** Changes require Part IV full 6-stage pipeline. Emergency suspension (Part IV) is the only bypass, requiring written justification.

### 9. Reference Implementations
- The Kernel itself (Parts I–V) is the current expression of USC
- Constitutional-Atlas/ is the reference system for USC

## UCE — Universal Constitutional Epistemology

### 1. Canonical Definition
The constitutional science of knowledge — the discipline within USC that governs what can be known, how truth is verified, and how knowledge is derived.

### 2. Constitutional Origin
Derived from USC. UCE is the first constitutional science because the constitution must first decide what can be known before reasoning about it.

### 3. Operational Meaning
UCE is the constitution's epistemic immune system. It prevents the system from claiming to know things it cannot verify. Every knowledge claim must pass UCE's rules before it can be used in governance or derivation.

### 4. Derivation Path
```
USC → UCE (constitutional science of knowledge)
```

### 5. Dependencies
- USC (epistemology without the Constitution has no authority to declare what is true)

### 6. Constraints
- Every knowledge claim must cite its source
- Unverifiable claims cannot enter the constitutional record
- UCE governs what is knowable within the system (epistemic boundaries)
- UCE does not produce knowledge — it governs knowledge production

### 7. Verification Criteria
- UCE is fully derived from USC
- UCE's rules are internally consistent
- UCE's scope is sufficient for constitutional reasoning (no gaps)
- UCE does not overreach (no claims about unknowable domains)

### 8. Governance Status
**Constitutional.** Changes require Part IV full pipeline + impact analysis on UCC and all downstream.

### 9. Reference Implementations
- Part III — Verification Framework Test 2 (Origin: can source be traced?)
- Part III — Verification Framework Test 6 (Verification: can truth be confirmed?)

## UCC — Universal Constitutional Calculus

### 1. Canonical Definition
The constitutional science of reasoning — the discipline within USC that governs how constitutional truths are derived, combined, and validated through formal logic.

### 2. Constitutional Origin
Derived from USC. UCC provides the logic for reasoning about what UCE classifies as knowable.

### 3. Operational Meaning
UCC is the constitution's logic engine. It ensures that every derivation in the system is formally valid — not just plausible, but provably correct within the constitutional framework.

### 4. Derivation Path
```
USC → UCC (constitutional science of reasoning)
UCE ─┘
```

### 5. Dependencies
- USC (the constitutional authority)
- UCE (calculus without epistemology manipulates symbols without meaning)

### 6. Constraints
- Every inference must follow formal rules
- Consistency: no contradiction within the logical system
- Derivations must be traceable to their premises
- UCC does not decide what is true — it decides what follows from what

### 7. Verification Criteria
- UCC is derived from USC and UCE
- Formal rules are internally consistent
- Every derivation in the kernel can be checked against UCC rules
- No circular reasoning exists in the logical framework

### 8. Governance Status
**Constitutional.** Changes require Part IV full pipeline + impact analysis on UCM and UCL.

### 9. Reference Implementations
- Part II — Derivation Rules (D1–D5) operationalize UCC
- Formal logic systems (through UCA)
- Proof assistants (Coq, Lean through UCA)

## UCL — Universal Constitutional Language

### 1. Canonical Definition
The constitutional science of expression — the canonical language for expressing constitutional meaning. The single semantic substrate from which all representations are derived.

### 2. Constitutional Origin
Derived from USC. UCL is the convergence point of all four sciences — knowledge (UCE), reasoning (UCC), and structure (UCM) produce expression (UCL).

### 3. Operational Meaning
UCL is the constitution's lingua franca. Every other layer — models, representations, visualizations, runtime — is expressed in UCL. Crucially, UCL separates meaning from serialization: meaning is constitutional; JSON-LD, CBOR-LD, and every other format are replaceable implementations.

### 4. Derivation Path
```
UCE ─┐
UCC ─┼→ UCL (constitutional science of expression)
UCM ─┘
```

### 5. Dependencies
- USC (the constitutional authority)
- UCE (expression requires knowledge)
- UCC (expression requires logic)
- UCM (expression requires mathematical structure)

### 6. Constraints
- Meaning is constitutional; serialization is replaceable (D4)
- UCL is the single semantic substrate — no competing languages
- UCL must be sufficient for UCRS and UCModels
- Changes to UCL meaning affect all downstream layers

### 7. Verification Criteria
- UCL is derived from all four predecessor sciences
- Semantic precision: no ambiguity in constitutional meaning
- UCL can express all constitutional concepts
- Serialization independence: meaning survives format changes

### 8. Governance Status
**Constitutional.** Changes require Part IV full pipeline + impact analysis on UCRS, UCModels, and all downstream. Meaning changes are Modification (highest impact).

### 9. Reference Implementations
- JSON-LD (default serialization through UCA)
- CBOR-LD (compact serialization through UCA)
- RDF 1.1 compatibility (W3C alignment)
